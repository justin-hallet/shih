# Space Harrier: Infinite Horizons - Controls Cheat Sheet

## Movement
| Key | Action | Description |
|-----|--------|-------------|
| **W** / **↑** / **Numpad 8** | Ascend | Fly higher (up to max flight height) |
| **S** / **↓** / **Numpad 2** | Descend | Fly lower (minimum floor clearance) |
| **A** / **←** / **Numpad 4** | Left Movement | Strafe left OR turn left (depends on movement mode) |
| **D** / **→** / **Numpad 6** | Right Movement | Strafe right OR turn right (depends on movement mode) |

## Combat
| Key | Action | Description |
|-----|--------|-------------|
| **Space** / **Enter** / **Shift** / **Numpad 5** | Fire | Shoot projectiles (weapon type depends on weapon level) |

## Speed Control
| Key | Action | Description |
|-----|--------|-------------|
| **=** / **Numpad +** | Speed Up | Increase forward movement speed (levels 1-5) |
| **-** / **Numpad -** | Speed Down | Decrease forward movement speed (levels 1-5) |

## Debug Weapons
| Key | Action | Description |
|-----|--------|-------------|
| **1** | Weapon Level 1 | Set weapon to Bullet |
| **2** | Weapon Level 2 | Set weapon to Missile |
| **3** | Weapon Level 3 | Set weapon to Laser |
| **4** | Weapon Level 4 | Set weapon to Plasma |
| **5** | Weapon Level 5 | Set weapon to Fireball |

## Visual Effects
| Key | Action | Description |
|-----|--------|-------------|
| **O** | Toggle Wireframe | Show/hide terrain wireframe overlay |
| **F** | Toggle Surface | Show/hide terrain surface |
| **C** | Toggle Cell Shading | Enable/disable cel-shading effect |
| **V** | Adjust Edge Threshold | Cycle through edge detection sensitivity |
| **B** | Adjust Color Levels | Cycle through color quantization levels |

## Debug Features
| Key | Action | Description |
|-----|--------|-------------|
| **6** | Debug Obstacles | Highlight obstacles with pink outline |
| **7** | Debug Enemies | Highlight enemies with red outline |
| **8** | Debug PowerUps | Highlight power-ups with green outline |
| **9** | Debug Collisions | Show/hide collision debug visualization |
| **P** | Cycle PowerUp Debug | Force spawn specific power-up types |
| **H** | Debug Hurt | Apply random damage to player (0.5-2.0) |
| **K** | Debug Kill | Trigger player death sequence |

## Interface
| Key | Action | Description |
|-----|--------|-------------|
| **`** (Backtick) | Toggle Debug Panel | Open/close settings and debug panel |
| **M** | Switch Model | Cycle through player model variants |

## Mobile/Desktop
- **Any key** on desktop when game shows "Play" button will start the game
- Touch controls automatically appear on mobile devices
- Virtual joystick for movement, fire button for shooting

## Movement Modes
The game supports two movement modes (configurable in settings):
- **Strafe Mode**: A/D keys move sideways while maintaining forward direction
- **Turn Mode**: A/D keys rotate the camera/player left and right

## Special Features
- **Automatic forward movement** - Player constantly moves forward at current speed level
- **Terrain following** - Altitude is maintained relative to ground below
- **Procedural world** - Infinite terrain generation as you explore
- **Power-ups** - Collect ammo, shields, weapon upgrades, speed boosts, and extra lives
- **Biome transitions** - Different terrain types as you travel
